# Egos Admin releases

Installers and the auto-update feed for **Egos Admin**, the Some Egos desktop admin app.
The source code is private; every installer here is signed and the app checks the signature
before updating.

## Install

Download **[EgosAdmin_0.5.0_x64-setup.exe](https://raw.githubusercontent.com/SomeEgos/SomeEgosRP-EgosAdmin-Releases/main/EgosAdmin_0.5.0_x64-setup.exe)** (version 0.5.0) and run it.
After that the app updates itself.
